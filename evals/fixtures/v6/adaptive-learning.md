# V6 专用评测夹具：透明掌握度与受控复习

PersonalLearning 使用版本化规则 `mastery-rule-v1` 聚合真实学习证据。掌握度与置信度分开：掌握度描述现有证据中的表现，置信度描述证据数量、多样性、新鲜度以及是否存在直接测验。缺少证据时知识点保持 `unassessed`，不能显示虚假零分。

复习调度由确定性代码完成。beginner 建议 1 天内复习，developing 建议 3 天内复习，proficient 建议 7 天内复习，strong 建议 14 天内复习；最近复习再次失败时次日复习。LLM 只能整理已经确定的原因，不能修改分数、置信度、优先级或日期。

Agent 查询掌握度和复习建议时只读取数据库真实记录。接受复习建议属于写操作，必须先冻结参数并展示人工确认；用户批准后才创建 DailyTask。重复批准必须复用已完成结果，不能创建第二个任务。
