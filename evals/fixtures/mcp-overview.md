# MCP Overview

Model Context Protocol (MCP) standardizes how AI applications connect to external
systems. An MCP host creates clients. Each client maintains a connection to one
MCP server. Servers can expose tools, resources, and prompt templates.

Tools are executable operations requested by a model and approved or controlled
by the host application. Resources expose readable contextual data identified
by URIs. Prompts are reusable message templates offered by a server.
