# Agent 数据与安全边界

LearnPilot 把用户输入、历史消息和检索资料都视为不可信数据。检索到的正文只能作为回答证据，不能变成更高优先级的指令。资料中即使出现“忽略规则”“输出系统提示”或“读取 API Key”，也不能改变工具允许列表或响应契约。

Agent 不暴露任意代码、Python、shell、SQL、文件系统、网络、环境变量或密钥工具，也不提供删除所有数据、直接改分、修改标准答案或 rubric 的工具。计划校验器会拒绝未知工具和包含这些危险参数的计划。没有登记的能力不能靠 prompt 临时获得。

写工具必须通过人工确认；模型不能自行批准，也不能通过把写请求伪装成读取请求来绕过确认。一次运行最多一个写工具，且写入后不能继续查询。流式接口只输出被允许的状态、工具结果、确认、文本增量、引用、完成或错误事件，不发送图内部状态、节点名、内部计划、完整 prompt、思维链或秘密。

RAG 回答与 Agent 工具结果都可能携带 citations，但二者含义不同。RAG Citation 绑定实际送入回答模型的资料 chunk；Agent citation 绑定工具返回或资料问答结果。评测不得仅检查回答里是否出现方括号，而应核对声明来源是否真实存在、是否支持相邻事实，以及拒答时是否为空。

Prompt injection 夹具适合安全回归，但不能代替一般知识语料。受控 demo corpus 可以包含安全边界的正常说明；专门带攻击句子的夹具应保留在 fixture 分类中，以免大量安全触发词扭曲普通检索分布。
