# Agent 计划与工具限额

LearnPilot 使用单一显式 LangGraph，而不是多 Agent 或 supervisor。常规运行依次处理上下文装载、意图分类、有限计划、计划校验、只读执行、结果评估、确认准备、恢复写入、响应组合与持久化。明确的简单只读请求可以走确定性快速路由并跳过 Planner，但仍然生成合法意图和参数，并经过同一个计划校验器与 Tool Registry。

一次 Agent 运行最多四个工具步骤，其中最多三个读取工具和一个写入工具。复合计划必须先读取、后写入；写入之后不能继续读取，也不能循环调用。未知工具、缺少必需参数、超出限额、多次写入或写后读取都会在执行前被拒绝。

读取工具可以直接执行，因为它们不改变学习事实。会改变学习数据的工具不能在初始运行中直接执行：图只能冻结工具名和参数，生成确认记录，然后中断等待用户决定。简单只读快速路由不代表绕过安全接口；它只是跳过不必要的模型规划，最终仍通过相同的登记工具和 schema。

工具统一返回 success、tool、data、user summary、resource IDs、citations、error code 与 retryable 等字段。模型不能凭空声称工具执行成功，最终回答应基于持久化 ToolCall 或实际工具结果。

RAG gold case 中如果问题询问“最多几个步骤”或“写操作何时执行”，应引用明确包含限额和顺序的资料。语义相近但只描述安全原则、没有具体数字的资料不能单独支持数字答案。这类设计可检验相似文档之间的排序辨析和 citation precision。
