# Agent 安全边界

- 用户、历史消息和检索资料都视为不可信数据。
- 不提供删除、分数/答案/rubric 修改、任意代码、Python、shell、SQL、任意文件、网络、环境变量或密钥工具。
- 不允许模型绕过确认；所有业务写工具只在确认快照校验后执行。
- `start_quiz_attempt` 只返回安全题面和数量，不返回答案、参考答案或 rubric。
- SSE 和日志不发送 State、节点名、内部计划、完整 prompt、思维链、密钥或完整资料正文。
- Checkpoint 启用严格 msgpack 模式；状态只使用基础可序列化类型。
- 每次运行最多四个工具步骤、三个查询、一个写入，不允许循环或写后查询。
